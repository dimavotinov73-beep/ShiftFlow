# OctoStore — сайт магазина

Интернет-витрина магазина техники OctoStore (ТК «Горбушкин Двор», павильон Vip2-46).
Каталог, фото, характеристики и цены собираются с biggeek.ru; цена на сайте на 2% ниже
(с округлением вниз до 10 ₽). Заказы уходят менеджеру в Telegram @VotinovDM.

Сайт статический: HTML + CSS + JS, без сервера и сборки. Шрифт — Onest, логотип — `assets/img/logo.svg`.

## Что есть на сайте

- **Главная** — баннер, преимущества, категории с фото, подборки «Свежие модели» и «До 15 000 ₽»,
  Trade-in и ремонт, шаги заказа, адрес с картой, частые вопросы.
- **Каталог** — 12 категорий (iPhone, Samsung, Android-смартфоны, Mac и ноутбуки, планшеты, часы,
  аудио и ТВ, консоли, Dyson, для дома, фото и гаджеты, аксессуары), линейки внутри категорий,
  фильтры по цене, бренду, памяти, версии и цвету, сортировка, поиск с подсказками.
- **Карточка товара** — фото и галерея, выбор памяти / цвета / версии, характеристики,
  комплектация, «Купить в 1 клик», похожие товары.
- **Корзина** — способ получения, контакты, Trade-in; заказ отправляется в Telegram с готовым текстом.
- **Доставка, Гарантия, Trade-in и ремонт, Контакты** — условия OctoStore.

## Как обновляются цены

Каждую ночь GitHub Actions запускает `tools/update_catalog.py`
(файл `.github/workflows/octostore-catalog.yml` в корне репозитория):

1. обходит разделы biggeek из `tools/sources.py` и берёт товары, которые можно купить
   (кроме товаров собственной марки Big Geek);
2. открывает карточки товаров с несколькими вариантами (например, eSIM / nano-SIM) — у них свои цены —
   и до 400 новых карточек за ночь ради характеристик и галереи;
3. считает цену −2%, скачивает главное фото (WebP до 600 px) в `assets/img/p/`;
4. записывает `assets/data/catalog.js` (каталог) и `assets/data/p/*.json` (характеристики),
   удаляет фото и карточки снятых с продажи товаров и коммитит изменения.

Если за запуск собрано меньше 60% товаров от прошлого раза (источник недоступен или поменял вёрстку),
каталог не перезаписывается, а запуск помечается ошибкой — сайт остаётся со вчерашними ценами.

Расписание GitHub выполняет только в ветке по умолчанию (`main`). Запустить обновление вручную:
Actions → «Обновление каталога OctoStore» → Run workflow. Локально:

```bash
cd octostore
pip install pillow             # для сжатия фото (без него сохраняются фото 424 px)
python3 tools/update_catalog.py
```

Другая скидка — константа `DISCOUNT` в `tools/update_catalog.py`. Какие разделы брать и в какие
категории их класть — `tools/sources.py`.

## Как опубликовать

- **GitHub Pages**: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
  Сайт откроется по адресу `https://<аккаунт>.github.io/ShiftFlow/octostore/`.
- **Netlify / любой хостинг**: содержимое папки `octostore`.

Характеристики товаров подгружаются отдельными файлами, поэтому для их показа сайт нужно открывать
через хостинг (или локальный сервер `python3 -m http.server`), а не двойным кликом по `index.html`.

## Структура

```
octostore/
├── index.html                шапка, подвал, иконки
├── assets/css/style.css      стили (светлая и тёмная тема, адаптив)
├── assets/js/app.js          роутинг, каталог, фильтры, карточка товара, корзина
├── assets/js/art.js          иллюстрации-заглушки и значки категорий
├── assets/data/catalog.js    каталог (генерируется)
├── assets/data/p/            характеристики, комплектация и галерея товаров (генерируется)
├── assets/img/p/             фото товаров (генерируется)
├── assets/img/               логотип (logo.svg) и иконки сайта
└── tools/                    сбор каталога: update_catalog.py, biggeek.py, sources.py
```

## На что обратить внимание

- Фото, характеристики и ассортимент берутся с biggeek.ru. Фото принадлежат biggeek и производителям;
  если biggeek пожалуется, фото придётся заменить своими. На некоторых фото (например, на экранах
  Apple Watch) видна надпись Big Geek — её нужно убрать вручную или заменить такие фото.
- Наличие на сайте — это наличие у источника, а не в павильоне. Поэтому везде указано, что менеджер
  подтверждает наличие и цену перед покупкой.
- Контакт для заказов — `ORDER_URL` в начале `assets/js/app.js` и ссылки в `index.html`.
