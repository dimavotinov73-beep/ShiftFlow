# OctoStore — сайт магазина

Сайт-витрина магазина техники [OctoStore](https://t.me/OctoStore46) (ТК «Горбушкин Двор», павильон Vip2-46).
Товары, цены, условия гарантии и доставки взяты из Telegram-канала.

Сайт статический: HTML + CSS + JS, без сервера и сборки. Работает на любом хостинге
и даже при открытии `index.html` с диска.

## Что есть на сайте

- **Главная** — баннер, преимущества, плитки категорий, баннеры линеек из канала, «Свежие модели»,
  «Подарки до 15 000 ₽», Trade-in и ремонт, шаги заказа, адрес с картой, частые вопросы.
- **Каталог** — 11 категорий: iPhone, Samsung Galaxy, Mac, Планшеты, Смарт-часы, Наушники и колонки,
  Яндекс Станции, Игры и консоли, Dyson, Фото и гаджеты, Аксессуары. Внутри — линейки
  (например, iPhone 17 Pro Max), фильтры по цене, бренду, памяти, SIM / вилке, цвету и сортировка.
- **Поиск** с подсказками; понимает запросы вроде «айфон 17 про макс 1тб», «макбук эйр 15», «дайсон фен».
- **Карточка товара** — выбор памяти, цвета и версии (SIM и регион, вилка Dyson), характеристики,
  «Купить в 1 клик» через Telegram, другие варианты линейки и похожие товары.
- **Корзина** — способ получения (самовывоз, курьер по Москве, за МКАД, регионы), контакты, Trade-in.
  Кнопка «Отправить заказ в Telegram» открывает чат с менеджером @lint_26 с готовым текстом заказа
  (текст также копируется в буфер обмена).
- **Доставка, Гарантия, Trade-in и ремонт, Контакты** — тексты из закреплённых постов канала.
- Мобильная версия с нижним меню, тёмная тема (по настройке системы).

## Как обновить цены

Цены лежат в `assets/data/catalog.js`. Их собирает скрипт из постов канала:

```bash
cd octostore
python3 tools/update_prices.py
```

Скрипт находит последний пост «Актуальный прайс» с кнопками-разделами, разбирает посты с ценами
и перезаписывает `assets/data/catalog.js`. Нужен только Python 3, сторонние библиотеки не требуются.

Скрипт рассчитан на текущий формат постов («Модель — цена₽», заголовки разделов, флаги регионов).
Если менеджер сильно поменяет формат, скрипт выведет строки, которые не смог разобрать, — их нужно поправить в посте
или дописать правило в `tools/update_prices.py`.

## Как опубликовать

- **GitHub Pages**: Settings → Pages → Deploy from a branch → ветка с сайтом, папка `/ (root)`.
  Сайт будет доступен по адресу `https://<аккаунт>.github.io/ShiftFlow/octostore/`.
- **Netlify / Vercel / любой хостинг**: загрузите содержимое папки `octostore` как есть.

## Структура

```
octostore/
├── index.html              каркас страницы, шапка, подвал, иконки
├── assets/css/style.css    стили (светлая и тёмная тема, адаптив)
├── assets/js/app.js        роутинг, каталог, фильтры, карточка товара, корзина
├── assets/js/art.js        SVG-иллюстрации товаров в цвете модели
├── assets/data/catalog.js  каталог (генерируется скриптом)
├── assets/img/             логотип и баннеры из канала
└── tools/update_prices.py  обновление каталога из Telegram
```

## На что обратить внимание

- В канале нет фотографий каждой модели, поэтому карточки товаров показывают нарисованные
  иллюстрации устройства в цвете модели. Баннеры категорий — настоящие картинки из канала.
- Значок 🚕 в прайсе показан на сайте как «На подвозе». Если он означает другое, поправьте подпись
  в `assets/js/app.js` (поиск по «На подвозе»).
- В канале про Trade-in и ремонт только одна строка, поэтому на сайте описан общий порядок
  (написать в Telegram → оценка → визит), без цен и сроков. Если появятся точные условия,
  допишите их в разделе `services` в `assets/js/app.js`.
