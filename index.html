🚀 Быстрый старт

\n

Чтобы запустить ShiftFlow локально, выполни следующие шаги:

\n \n

1. Клонируй репозиторий:

\n
git clone https://github.com/dimavotinov73-beep/ShiftFlow.git
cd ShiftFlow
\n\n

2. Установи зависимости:

\n
flutter pub get
\n\n

3. Собери APK для Android:

\n
flutter build apk --release
\n\n

4. Или запусти на эмуляторе:

\n
flutter run
\n\n

Готовый APK будет в папке: build/app/outputs/flutter-apk/app-release.apk
