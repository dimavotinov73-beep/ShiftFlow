# ShiftFlow в RuStore: соответствие требованиям и публикация

Коротко: ShiftFlow не собирает персональные данные. Всё, что вводит пользователь, хранится только на его телефоне.
Сборка для RuStore не обращается в интернет, в ней нет рекламы, аккаунтов, входа через Google/Apple, аналитики,
сторонних библиотек и рекомендательных алгоритмов. Поэтому большая часть требований закона к приложению не применяется.
Что осталось сделать тебе — в разделе «Что сделать перед отправкой».

Это разбор по пунктам, а не юридическое заключение. Если сомневаешься в конкретном пункте, покажи этот файл юристу.

## 1. Российское законодательство

### 152-ФЗ «О персональных данных»

| Требование | Как в ShiftFlow |
|---|---|
| Отдельное согласие на обработку ПДн (с 1 сентября 2025) | **Не требуется.** Приложение ничего не собирает: смены, ставки и заметки лежат в памяти телефона, разработчик их не получает. В политике (раздел 2) прямо сказано, что разработчик не оператор этих данных. |
| Локализация данных на серверах в РФ | **Выполнено автоматически.** Сервера нет, данные хранятся на устройстве самого пользователя. |
| Уведомление РКН об утечках (24 и 72 часа) | **Неприменимо.** Нет базы данных, из которой может что-то утечь. |
| Обращения в поддержку | Единственное, что разработчик получает, — письмо, которое пользователь пишет сам. Основание — исполнение Пользовательского соглашения по запросу пользователя (п. 5 ч. 1 ст. 6 152-ФЗ), отдельное согласие не нужно. Это описано в политике, раздел 4. |
| Почта поддержки | ⚠️ Сейчас `shiftflow123@gmail.com` — это зарубежный сервис: письма с адресами пользователей хранятся вне РФ. Для чистоты по локализации лучше завести ящик на российском сервисе (Яндекс Почта, Mail.ru) и поменять его в одном месте: `SUPPORT_EMAIL` в `web/app.js`, затем `node tools/legal/build-legal-pages.js` и строку «Почта поддержки» в `store/listing-ru.md`. |

### 436-ФЗ «О защите детей от информации…»

| Требование | Как в ShiftFlow |
|---|---|
| Возрастная категория (знак информационной продукции) | **0+**: учёт смен и денег, нет запрещённой для детей информации. Знак `0+` стоит в «Настройках» внизу (рядом с номером версии) и в политике конфиденциальности, раздел 8. В RuStore выбери возраст **0+**. |
| «Мне есть 14 лет» в соглашении | Это не возрастная маркировка контента, а возраст, с которого человек может сам принять оферту. Противоречия с 0+ нет. |

### 149-ФЗ «Об информации…»

| Требование | Как в ShiftFlow |
|---|---|
| Запрещённый контент | Нет: приложение показывает только то, что ввёл сам пользователь. |
| Запрет входа через иностранные сервисы (Apple ID, Google) | **Неприменимо:** входа и регистрации нет вообще. |
| Рекомендательные технологии (ст. 10.2-2) | **Неприменимо:** нет ленты и алгоритмов, которые что-то рекомендуют. Публиковать правила не нужно. |

### Реклама и особые категории

| Требование | Как в ShiftFlow |
|---|---|
| Маркировка рекламы | Рекламы нет, маркировать нечего. |
| Азартные игры, VPN, кредиты | Не относится. |

## 2. Требования RuStore

| Требование | Как в ShiftFlow |
|---|---|
| Статус разработчика | Регистрируешься в https://console.rustore.ru через VK ID и выбираешь статус. В твоих требованиях указаны ИП, самозанятый или юрлицо; в консоли могут быть доступны и другие варианты. Для бесплатного приложения без платежей подойдёт любой доступный тебе статус, смотри актуальный список при регистрации. |
| Политика конфиденциальности (ссылка) | После слияния этой ветки в `main` политика будет на GitHub Pages: https://dimavotinov73-beep.github.io/ShiftFlow/web/privacy.html, соглашение — https://dimavotinov73-beep.github.io/ShiftFlow/web/terms.html. ⚠️ Старый адрес `blue-rain-2af9…workers.dev/privacy.html` сейчас отдаёт 404, а Cloudflare в России открывается с перебоями — модератор может не открыть ссылку. Используй адрес GitHub Pages. |
| Возрастной рейтинг | 0+. |
| Стабильная работа, все функции работают | Перед отправкой пройди проверку из раздела 4 на своём телефоне. |
| Нет скрытых функций и неавторизованных библиотек | В приложении нет сторонних SDK: только Android и WebView, интерфейс загружается из файлов внутри APK. Сборка с `-Pchannel=rustore` не скачивает APK в обход магазина и не обращается к серверу обновлений: кнопка «Открыть в магазине» ведёт на страницу RuStore. |
| Платежи (RuStore Pay) | Не нужны: приложение бесплатное, покупок внутри нет. |
| Разрешения | Только «Интернет» (в сборке для RuStore не используется, остаётся в манифесте общим для всех сборок). Контакты, камера, микрофон, геолокация, файлы не запрашиваются: экспорт идёт через системное окно выбора файла. |

## 3. Что сделать перед отправкой

1. **Слить ветку в `main`.** Так заработают ссылки на политику и соглашение на GitHub Pages.
2. **Проверить ссылки в браузере с телефона без VPN.** Должны открываться `…/web/privacy.html` и `…/web/terms.html`.
3. **(Желательно) Российская почта поддержки** вместо Gmail — см. раздел 152-ФЗ выше.
4. **Ключ подписи.** Создай upload-ключ (`store/RELEASE.md`, шаг 0.3) и храни его в надёжном месте: без него не выпустишь обновление.
5. **Собрать релиз для RuStore:**
   - **Локально:** в `android/` выполни `./gradlew assembleRelease -Pchannel=rustore`. Файл — `app/build/outputs/apk/release/app-release.apk`.
   - **В GitHub Actions:** добавь секреты `SF_KEYSTORE_BASE64`, `SF_KEYSTORE_PASSWORD`, `SF_KEY_ALIAS`, `SF_KEY_PASSWORD` и запусти workflow «Android». Workflow сейчас собирает релиз с каналом по умолчанию (play), поэтому для RuStore удобнее собрать локально или добавить в workflow `-Pchannel=rustore`.
6. **Карточка в консоли:**
   - тексты — из `store/listing-ru.md`;
   - значок и скриншоты — из `store/rustore/` (раздел 4);
   - возраст — 0+;
   - ссылки — на политику и соглашение (GitHub Pages);
   - почта поддержки.
7. **Отправить на модерацию.** Обычно она занимает 1–3 рабочих дня.

## 4. Картинки для карточки

Всё для загрузки лежит в **`store/rustore/`** — бери файлы оттуда:

| Поле в консоли | Файл | Требование RuStore | Как у нас |
|---|---|---|---|
| Иконка | `icon-512.png` | 512×512, PNG/JPG, до 3 МБ, фон на всю площадь без прозрачности | 512×512 PNG, 8 КБ, тёмный фон во весь квадрат (углы RuStore скругляет сам) |
| Скриншоты телефона | `screenshots/01…06.png` | не меньше 3, PNG/JPG, до 3 МБ, не больше 2160×3840, вертикальные 9:16 | 6 штук, 1080×1920 (9:16), 0,2–0,3 МБ |
| Аватар разработчика / группы VK | `avatar-400.png` | — | знак вписан в круг |

Скриншоты в порядке загрузки:
1. Календарь смен.
2. Две работы в одном дне — новая функция.
3. Финансы за месяц.
4. Статистика за год.
5. Шаблон 2/2.
6. Оформление.

Английские скриншоты (для Google Play) лежат в `store/screenshots/en/`, логотипы для сайта и соцсетей — в `store/brand/` (см. `store/brand/README.md`).
Скриншоты для планшета и видео на карточку необязательны.

## 5. Проверка на телефоне перед отправкой

- [ ] Первый запуск: показывается соглашение, после согласия открывается календарь
- [ ] Смена в один день, затем «Добавить ещё смену в этот день» — вторая смена другого места работы, у каждой свои часы и оплата, внизу «Итого за день»
- [ ] Убрать смену → «Вернуть»; заменить место работы у смены; выходной; заметка
- [ ] Шаблон графика 2/2 на месяц, затем шаблон второго места — смены добавились к уже отмеченным дням
- [ ] Финансы: итог месяца и статистика за год сходятся со сменами
- [ ] Экспорт в Excel/CSV и импорт обратно (без дублей), резервная копия
- [ ] Виджеты «Сегодня», «Неделя», «Месяц»; в дне с двумя сменами — оба места работы и «+N»
- [ ] Тёмная и светлая тема, кнопка «Назад», поворот экрана
- [ ] В авиарежиме всё работает так же
