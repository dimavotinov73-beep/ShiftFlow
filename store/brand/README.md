# Логотип ShiftFlow

**Знак** — «день» (мятный шар), который лежит в изгибе линии графика. Та же форма, что у кнопки на нижней панели приложения.
**Надпись** — SHIFTFLOW шрифтом Sofia Sans Extra Condensed Black. SHIFT цветом бумаги или чернил, FLOW мятным.
**Девиз** — «Твой график — твой доход» шрифтом Caveat, как подписи «от руки» в приложении.

Текст в SVG переведён в контуры, поэтому файлы открываются одинаково везде, установка шрифтов не нужна.
Шрифты распространяются по лицензии SIL Open Font License 1.1.

## Цвета

| Цвет | Код | Где |
|---|---|---|
| Чернила | `#1F1D1A` | фон значка, надпись на светлом |
| Бумага | `#F3EFE4` | линия знака и надпись на тёмном |
| Светлая бумага | `#ECE7DA` | подложка на светлом |
| Мята | `#3DDCB0` | шар и FLOW на тёмном |
| Тёмная мята | `#14806A` | шар и FLOW на светлом (мята там слабо читается) |

## Файлы

| Файл | Для чего |
|---|---|
| `shiftflow-logo-dark.svg` / `-light.svg` | Горизонтальный логотип без фона: для тёмного или светлого фона (сайт, презентации, шапки) |
| `shiftflow-logo-tagline-dark.svg` / `-light.svg` | То же с девизом |
| `shiftflow-logo-on-ink.svg` / `-on-paper.svg` | Логотип с девизом на подложке — баннеры, обложки |
| `shiftflow-stacked-on-ink.svg` / `-on-paper.svg` | Квадрат: знак над надписью — соцсети, посты |
| `shiftflow-mark-dark.svg` / `-light.svg` | Только знак без фона |
| `shiftflow-icon.svg` / `-icon-rounded.svg` | Значок приложения: квадрат во весь фон (магазины) и со скруглением |
| `shiftflow-avatar.svg` | Аватар 400×400, знак вписан в круг (группа VK, страница разработчика) |
| `png/` | Готовые PNG тех же файлов (размер в имени) |

Пересобрать: `pip install fonttools brotli && python3 tools/brand/build-logo.py && node tools/brand/render-logo.mjs`.
Значки самого приложения (лаунчер, веб, магазины) собирает `node tools/brand/build-icons.mjs` из того же знака.
